
**Salma IPTV** is a Progressive Web App (PWA) designed to stream **Moroccan, Arabic, and international news channels** with a clean, mobile-first interface.

### 🌍 About

Salma IPTV focuses exclusively on **legal and public news channels**, providing users with a fast, lightweight, and accessible experience — whether on desktop or mobile.
The app supports **M3U playlist uploads**, allowing users to add and manage their favorite channels easily.

### 🧩 Features

* 🇲🇦 Live Moroccan TV channels
* 🌐 Arabic & international news channels
* 📰 Optimized for news and public TV streams only
* 📱 Mobile-first responsive interface
* 💾 Upload and manage M3U playlists
* 🌗 Dual language: English / Arabic
* ⚡ Works offline as a Progressive Web App (PWA)
* 🧠 Built with React + Express

### ⚖️ Legal Note

Salma IPTV does **not host or distribute copyrighted content**.
It only provides access to **freely available public streams** and supports user-provided M3U playlists for personal, legal use.
